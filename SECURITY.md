# Security Policy

## Supported Versions

Kami secara aktif memelihara dan memberikan patch keamanan untuk versi rilis berikut:

| Version | Supported          |
| ------- | ------------------ |
| 1.6.x   | :white_check_mark: |
| < 1.6.0 | :x:                |

## Reporting a Vulnerability

Keamanan proyek dan pengguna adalah prioritas utama kami.

Jika Anda menemukan celah keamanan (*security vulnerability*) pada README-Architect:
1. **Dilarang** membuka GitHub Issue publik untuk kerentanan keamanan yang belum tertangani.
2. Silakan laporkan secara privat melalui fitur **[Private Vulnerability Reporting](https://github.com/hanifalkauni/readme-architect/security/advisories/new)** di tab Security repositori GitHub kami.
3. Tim maintainer akan menanggapi laporan Anda dalam waktu **1x24 jam** dan memberikan update terkait timeline patch.
