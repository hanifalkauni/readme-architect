# GitHub Copilot Documentation Instructions
When generating or refactoring project README.md:
- Strictly adhere to verified scripts in `package.json`, `Makefile`, or `pyproject.toml`.
- Provide modern formatting with centered headers, themed badges, and 14-section comprehensive layout.
- Ensure all badges have descriptive alt-text compliant with WCAG 2.2 Level AA.
- Preserve human-written notes marked with `<!-- user-content -->`.
